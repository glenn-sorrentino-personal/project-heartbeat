# Project Heartbeat MVP

This package was generated by Project Heartbeat.

## Included repositories

- App repo: octo-org/heartbeat-app
- Screenshots repo: octo-org/heartbeat-screenshots
- Social repo: octo-org/heartbeat-social

## Install order

1. Copy each top-level repo folder into the matching GitHub repository.
2. Add the required GitHub Actions secrets listed in `docs/project-heartbeat/README.md`.
3. Review `heartbeat.config.json` in each repo.
4. Run the generated workflows in dry-run mode first.

## Runtime model

- Setup is static and generated locally.
- Scheduled execution happens in GitHub Actions.
- Long-lived secrets belong in repository or organization secrets, not in the frontend app.
